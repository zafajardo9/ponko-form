# PonkoForm Flow Builder — Vision

## North Star

Empower form creators to build **dynamic, business-process-driven forms** as visual flowcharts — where each step (question, calculation, decision, payment, or destination) is a node connected to the next. Forms become living workflows that respond to user input, compute values, route conditionally, collect payments, and deliver post-completion summaries.

## What Problem This Solves

Traditional form builders produce linear, static forms. But real-world business processes are rarely linear. A payment form might:

1. Ask for the customer's chosen plan
2. Calculate VAT + total based on plan selection
3. If "Installment" show monthly breakdown; if "Full Payment" show one-time price
4. Collect payment via a gateway
5. Redirect to a summary/receipt page

Today, building this requires custom code. Our Flow Builder makes it visual and no-code.

## Target User

- **Form creators** (business owners, product managers, operations teams) who need to build multi-step, conditional, payment-enabled forms without engineering help.
- **End users** (form respondents) who experience a smooth, context-aware flow with calculators, conditional sections, and integrated payment.

## Key Experience Pillars

| Pillar | Description |
|---|---|
| **Visual Flow Composition** | Build forms as node-based flowcharts — add, connect, and configure nodes on a canvas |
| **Variable System** | Creators define typed variables; nodes read/write them; calculators transform them |
| **Rich Node Types** | Form fields, decisions, calculators, payments, result pages, redirects |
| **Conditional Branching** | Decision nodes route users down different paths based on their input |
| **Payment Handoff** | Flow passes computed totals to any registered payment gateway |
| **Post-Completion** | Show dynamic summary, receipt, or redirect after submission + payment |
